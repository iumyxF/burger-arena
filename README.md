# 汉堡竞技场 · BURGER ARENA

把熟悉的麦当劳餐品，搭配成你的生存武器。

## 项目介绍

《汉堡竞技场》是一款餐厅像素风的 2D 生存 Roguelike 小游戏。每局十波、纯战斗约六分钟：自动攻击、走位拾取，波后选择成长属性，再到商店购买餐品、合成武器，准备迎接下一波。商店没有倒计时，可以慢慢搭配。

游戏将麦当劳中国 MCP 提供的真实餐品营养数据融入卡牌：热量、蛋白质、脂肪、碳水等数据参与属性和风味词条的生成。巨无霸、大薯条、麦乐鸡等餐品因此拥有各自的战斗特色。

- **短局即玩**：打开浏览器就能开始，无需注册或登录。
- **六种武器**：连射、散射、追踪、穿透、爆炸、弹射，尝试不同打法。
- **六槽构筑**：允许重复武器，两把同种同品质合成；白、蓝、紫、金四档，金色解锁独特进化。
- **材料经济**：战斗升级选属性，商店买装备；锁定、刷新、出售和急救都需要取舍。
- **餐品有代价**：例如麦咖啡因提高暴击但降低最大生命，玉米壁垒增加护甲但降低移速。
- **离线体验**：项目已内置营养数据，游玩无需联网或配置 Token。

## 目标用户

- 想在休息时间玩一局的轻度玩家。
- 喜欢自动攻击、生存挑战和卡牌搭配的 Roguelike 玩家。
- 对麦当劳餐品主题、像素风或真实数据创意应用感兴趣的人。

当前主要面向使用键盘的电脑浏览器玩家，暂不支持触屏和手柄。

## 安装与启动

1. 下载项目并解压，或将仓库克隆到本地。
2. 使用电脑浏览器打开项目中的 `index.html`。
3. 选择初始武器，确认后开始游戏。

游戏无需安装依赖或构建。如需通过本地网址访问，可在已安装 Python 3 的电脑上，进入项目目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

然后打开 [本地游戏页面](http://localhost:8080)。Windows 也可使用 `py -m http.server 8080 --bind 127.0.0.1`。

## 使用示例

第一次游玩，可以选择「巨无霸连射枪」开局。战斗中升级不会弹窗，先专心走位；波后全额收集剩余材料和经验，恢复 15% 最大生命，再依次选择属性。到商店补充武器或购买餐品道具，按“准备好了，开始下一波”继续。也可以装备六把同种武器，或将重复武器合成更高品质。

| 操作 | 按键 |
|---|---|
| 选择初始武器 | `1–6` 或方向键 |
| 确认开局 | `Enter` |
| 移动 | `WASD` 或方向键 |
| 波后选择成长属性 | `1 / 2 / 3` |
| 商店购买、刷新、锁定、合成、出售 | 点击对应按钮，或 `Tab` 聚焦后按 `Enter` |
| 暂停、查看装备 | `Esc` |
| 查看武器槽详情 | 鼠标悬停或按 `Tab` 聚焦 |

## 十波与构筑规则

每波时长依次为 **25、25、30、30、35、35、40、40、45、45 秒**，纯战斗共 350 秒。第四波中途出现一名精英，第八波出现两名，第十波 Boss 登场。非最终波只需坚持到时间结束；第十波存活通关评 A，提前击杀 Boss 评 S，死亡评 C。

- 每点材料价值获得 **1 材料和 1 基础经验**；经验加成不会复制材料。波末全额补收掉落、领取本波营业收益，再恢复最大生命的 15%。伤势跨波保留。
- 升级经验需求为 `12 + 10 × (当前等级 − 1)`，等级只提供生命、伤害、攻速、移速、护甲、回复、暴击或营业收益。波后选择的新营业收益从下一波结算起生效。
- 武器品质伤害倍率为 `1 / 1.3 / 1.65 / 2`，攻击间隔倍率为 `1 / 0.97 / 0.94 / 0.91`；金色另获三连发、更多散弹、双追踪弹、更强穿透、更大爆炸或更多弹射等独特效果。
- 同种武器允许重复装备。**购买不会自动合成**；满六槽时，可在存在同种同品质副本的情况下选择“购买并合成”。金色不可继续合成。
- 营养伤害与暴击作用于单件武器；全局风味加成按不同武器种类只计一次。各属性百分比加成先累加，再计算有效值。护甲为正时伤害倍率为 `1/(1+0.08×护甲)`，负护甲则为 `1−0.08×护甲`。

| 餐品道具（每种最多五份） | 每份收益 | 每份代价 | 基础价 |
|---|---|---|---|
| 沙拉护甲 | 最大生命 +20、每秒回复 +0.5 | 伤害 −6% | 20 |
| 薯饼加压 | 攻速 +15% | 移速 −4% | 18 |
| 冰爽可乐 | 移速 +8% | 伤害 −5% | 14 |
| 旋风磁力 | 拾取范围 +25%、经验 +15% | 攻速 −8% | 18 |
| 玉米壁垒 | 护甲 +3 | 移速 −6% | 20 |
| 麦咖啡因 | 暴击 +8 个百分点 | 最大生命 −15 | 18 |

### 波间商店

前九波之后开放商店。新一轮首屏通常两件武器、两件道具；跨波锁定优先保留，不会为了凑比例替换已锁定商品。购买后不会立即补货，刷新才重新生成未锁定格。道具仅购买、不出售；武器出售返还当前参考价的 50%，向下取整。

武器基础价 16，品质价格倍率 `1 / 1.8 / 3.1 / 5.2`；商品售价为 `ceil(基础价 × 品质倍率 × (1 + 0.08 × 已完成波数))`，锁定商品保留旧价格。后期更容易出现高品质武器。

刷新费用为 `2 + floor(已完成波数/2) + 2 × 本店刷新次数`，每店重新计数，四格全锁不能刷新。每店可购买一次急救，价格 `8 + 3 × 已完成波数`，恢复 30% 最大生命。界面会展示属性变化、材料不足、槽位和合成限制。

## 餐品数据与 MCP

项目通过麦当劳中国 MCP 的 `list-nutrition-foods` 获取餐品营养数据，并预先写入游戏。普通玩家无需执行这一步；需要刷新数据或了解接入方式时，请阅读 [MCP 集成说明](MCP_INTEGRATION.md)，其中包含配置方法、实际 Tool、调用流程和业务价值。

## 开发验证

游戏本身零依赖。开发验证需安装 Playwright 并有可用的 Chrome，执行 `node tools/verify-game.cjs`；若 Playwright 位于共享目录，可用 `NODE_PATH` 指定。可选环境变量 `BURGER_SCREENSHOTS` 指定截图输出目录。

脚本覆盖武器白/金品质机制、空间查询、经济守恒、重复装备、合成与出售、刷新锁定、属性取舍、波后成长、死亡/计时/Boss 判定，以及 480/960/1280 宽度的界面、音频释放和压力回放。

固定随机种子回放会输出六种初始武器的首波生存情况、专精与混合六槽构筑的十波收支和品质进度，以及一条从正常开局开始、使用正常生命与收入的自动试玩记录。六槽构筑流程测试会补充生命以隔离操作水平；正常开局试玩不使用此辅助，二者在输出中分开记录。

当前 Chrome 无头模式回放：六槽金色、105 个敌人和 1200 点地上材料压力场景的 P95 帧间隔约 16.8ms，更新/绘制 P95 约 0.7/1.8ms，弹体峰值 27。自动试玩不是人工通关或全面强度平衡结论。

## 项目说明

本项目为非官方同人作品，与麦当劳中国无隶属关系；像素画与音效由代码生成，不使用官方素材。营养数据在游戏中用于创意玩法，游戏属性不构成营养或健康建议。

当前版本专注单局体验，暂未提供存档、局外成长、多角色或多地图。参赛相关声明见 [参赛声明](CONTEST_DECLARATION.md)。
