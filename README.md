# 汉堡竞技场 · BURGER ARENA

把熟悉的麦当劳餐品，搭配成你的生存武器。

## 项目介绍

《汉堡竞技场》是一款餐厅像素风的 2D 生存 Roguelike 小游戏。每局 5 分钟，武器自动攻击，你只需走位、收集经验，在升级时挑选卡牌，迎战不断涌来的敌人和最终 Boss。

游戏将麦当劳中国 MCP 提供的真实餐品营养数据融入卡牌：热量、蛋白质、脂肪、碳水等数据参与属性和风味词条的生成。巨无霸、大薯条、麦乐鸡等餐品因此拥有各自的战斗特色。

- **短局即玩**：打开浏览器就能开始，无需注册或登录。
- **六种武器**：连射、散射、追踪、穿透、爆炸、弹射，尝试不同打法。
- **自由搭配**：组合武器与辅助卡，每张卡最高 5 级，武器满级获得独特进化。
- **离线体验**：项目已内置营养数据，游玩无需联网或配置 Token。

## 目标用户

- 想在休息时间玩一局的轻度玩家。
- 喜欢自动攻击、生存挑战和卡牌搭配的 Roguelike 玩家。
- 对麦当劳餐品主题、像素风或真实数据创意应用感兴趣的人。

当前主要面向使用键盘的电脑浏览器玩家，暂不支持触屏和手柄。

## 安装与启动

1. 下载项目并解压，或将仓库克隆到本地。
2. 使用电脑浏览器打开项目中的 `index.html`。
3. 选择初始武器，确认后开始游戏。

游戏无需安装依赖或构建。如需通过本地网址访问，可在已安装 Python 3 的电脑上，进入项目目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

然后打开 [本地游戏页面](http://localhost:8080)。Windows 也可使用 `py -m http.server 8080 --bind 127.0.0.1`。

## 使用示例

第一次游玩，可以选择「巨无霸连射枪」开局，边移动边自动攻击，收集经验后选择升级已有武器，或加入新武器与辅助卡。接近敌群时可以尝试「薯条霰弹枪」，想保持距离则可尝试「辣堡穿透炮」。

| 操作 | 按键 |
|---|---|
| 选择初始武器 | `1–6` 或方向键 |
| 确认开局 | `Enter` |
| 移动 | `WASD` 或方向键 |
| 升级时选择卡牌 | `1 / 2 / 3` |
| 暂停、查看装备 | `Esc` |
| 查看武器槽详情 | 鼠标悬停或按 `Tab` 聚焦 |

随着时间推进，精英敌人和场地障碍会加入战斗；第 4 分钟 Boss 登场，第 5 分钟打烊结算。尝试活到最后，挑战更高评级。

## 餐品数据与 MCP

项目通过麦当劳中国 MCP 的 `list-nutrition-foods` 获取餐品营养数据，并预先写入游戏。普通玩家无需执行这一步；需要刷新数据或了解接入方式时，请阅读 [MCP 集成说明](MCP_INTEGRATION.md)，其中包含配置方法、实际 Tool、调用流程和业务价值。

## 开发验证

游戏本身零依赖。开发验证需安装 Playwright 并有可用的 Chrome，执行 `node tools/verify-game.cjs`；若 Playwright 位于共享目录，可用 `NODE_PATH` 指定。可选环境变量 `BURGER_SCREENSHOTS` 指定截图输出目录。

脚本覆盖六种武器一级与五级机制、弹体命中与射程、开局选择、装备详情、小窗口滚动、六种初始武器的 60 秒自动走位生存、完整五分钟模拟、音频释放及压力回放。2026-10-22 回归通过 1115 项机制断言及界面检查；满级六武器压力场景 P95 帧间隔约 16.8ms，弹体峰值 32。结果来自 Chrome 无头模式，不代表人工通关或武器强度已经平衡。

## 项目说明

本项目为非官方同人作品，与麦当劳中国无隶属关系；像素画与音效由代码生成，不使用官方素材。营养数据在游戏中用于创意玩法，游戏属性不构成营养或健康建议。

当前版本专注单局体验，暂未提供存档、局外成长、多角色或多地图。参赛相关声明见 [参赛声明](CONTEST_DECLARATION.md)。
