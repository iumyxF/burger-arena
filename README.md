# 汉堡竞技场 · BURGER ARENA

极简灰像素风的《吸血鬼幸存者》式 2D 生存 Roguelike。单局 5 分钟，武器全自动，
你只负责走位——然后把麦当劳**真实营养数据**吃成一套 Build。

> 非官方同人作品，与麦当劳中国无隶属关系；不使用官方素材，全部像素画与音效由代码生成。

## 运行

双击 `index.html` 即可（`file://` 直接跑，零依赖、零构建）。

需要本地服务器时：

```bash
python3 -m http.server 8080   # 打开 http://localhost:8080
```

操作：`WASD` / 方向键移动 · 自动攻击 · `1/2/3` 选卡 · `ESC` 暂停。

## 营养数据 → 卡牌属性

数据来自麦当劳中国 MCP 的 `list-nutrition-foods`（160 条餐品，含能量、蛋白质、
脂肪、碳水化合物、钠、钙）。**游戏不直接读网络**：构建期用脚本抓取并内联进 HTML。

先归一化，再派生：

```
K = clamp(kcal/550, .30, 1.6)      P = clamp(protein/25, .20, 1.6)
C = clamp(carb/45, .20, 1.6)       F = clamp(fat/28, .10, 1.6)
S = clamp(sodium/900, .05, 1.6)

伤害倍率 = 0.70 + 0.60K            冷却倍率 = 1 / (0.72 + 0.45C)
弹体加成 = floor((F - .45) * 1.4)  范围倍率 = 0.85 + 0.45F
暴击     = .03 + .14(S - .40)
```

再按**热量占比**（蛋白×4 / 碳水×4 / 脂肪×9）给每张卡一个风味词条，
占比最高且 > 42% 才触发，所以「高脂肪」的巨无霸和「高碳水」的大薯条手感确实不一样：

| 词条 | 效果 |
|---|---|
| 高蛋白 | 命中回护盾 |
| 高碳水 | 攻速 +10%、移速 +5% |
| 高脂肪 | 该武器弹体 +1、范围 +15% |
| 高钠 | 暴击 +8%、击退 +30% |
| 热量炸弹 | 伤害 +15%、冷却 +10% |
| 咖啡因 | 攻速 +8%、暴击 +5% |

### 卡池

武器（形态互不重复）：双层环刃（巨无霸，环绕）、薯条霰弹（大薯条，扇形）、
鸡块追猎（麦乐鸡，追踪）、辣堡冲拳（麦辣鸡腿汉堡，冲刺）、派皮轰炸（香芋派，抛物线爆炸）、
鳕鱼声波（麦香鱼，扩散环）。

通用：沙拉护甲（鲜蔬蛋沙拉叠叠卷）、薯饼加压（脆薯饼）、冰爽可乐（可乐中杯）、
旋风磁力（奥利奥麦旋风）、玉米壁垒（大杯玉米杯）、麦咖啡因（冰美式中杯）。

每张卡 5 级，第 5 级「金拱进化」：变金色、伤害 ×1.25、弹体 +1。卡面底部永远显示
该餐品的真实 kcal / 蛋白 / 碳水 / 脂肪。

## 刷新真实数据

首次运行下方命令会在项目根目录自动创建 `mcd.config.json`，并提示填写 token。
也可以先复制 `mcd.config.example.json` 为 `mcd.config.json`。编辑配置文件：

```json
{
  "MCD_MCP_TOKEN": "你的token"
}
```

Token 在 https://open.mcd.cn/mcp 申请（手机号登录 → 控制台 → 申请 MCP Token）。
保存配置后运行：

```bash
node tools/fetch-mcd.mjs

node tools/fetch-mcd.mjs --dry        # 只看结果，不写文件
node tools/fetch-mcd.mjs --out d.json # 导出 JSON
```

脚本会走 `initialize → tools/call list-nutrition-foods`，解析 CSV 表格，
替换 `index.html` 里 `/*MCD:START*/` 到 `/*MCD:END*/` 之间的数据块。
Token 只从项目根目录的 `mcd.config.json` 读取，**不会写进 HTML**；该文件已被 Git 忽略，请勿将其公开或放入公开静态服务器目录。
未填写 token 时，脚本会提示配置文件位置及申请地址并退出；配置格式错误时也会给出提示。
直接打开游戏仍使用上一次注入的数据，无需 token。

## 实现说明（单文件，约 2000 行）

- 世界渲染在 480×270 的 canvas 上，整数/半整数倍放大 + `image-rendering: pixelated`
- 中文 HUD 与卡牌全部是 DOM 覆盖层，避免低分辨率下糊掉
- 所有贴图在加载时烘焙成离屏 canvas（含白色受击闪图），绘制只走 `drawImage`
- 音效与 BGM 全部 WebAudio 合成：总线 `lowpass 6.8k → compressor → 0.55`，
  起音 ≥ 5ms、单音 ≤ 0.2，避免刺耳
- 打击反馈：hitstop、trauma 震屏、闪白、击退、粒子、像素飘字、慢动作、暗角
